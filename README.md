## Overview

This VS Code extension provides **syntax highlighting** for **RJS** – a Russian‑flavoured version of JavaScript. The colour scheme follows the **Russian flag**:
- **Blue** (`#0039A6`) for keywords and types
- **Red** (`#D52B1E`) for strings and numbers
- **White** (`#FFFFFF`) for comments

It also adds scopes for functions, variables, and numeric literals, giving a vibrant and distinctive look to RJS code.

## Features
- Language support for files with the `.rjs` extension
- Full keyword highlighting in Russian terms (e.g., `если`, `функция`, `возврат`)
- Russian‑flag colour theme (blue, red, white)
- Auto‑closing brackets and comment handling via `language-configuration.json`

## Installation

### From the VS Code Marketplace (once published)
1. Open **Extensions** (`⇧⌘X`).
2. Search for **RJS Flag Theme** and click **Install**.

### Local development / testing
```bash
# Clone the repository
git clone https://github.com/yourusername/rjs-vscode.git
cd rjs-vscode/rjs-syntax

# Install dependencies
npm install

# Launch a development host
code .
# Press F5 to run the Extension Development Host
```
Open a file with the `.rjs` extension in the new window to see the highlighting.

## Usage
Create a file with the `.rjs` extension and start coding. Example:
```rjs
// пример комментария
перем x = "строка";
если (x) {
    функция привет() {
        возврат "Привет, мир!";
    }
}
```
You should see the Russian‑flag colours applied as described above.
